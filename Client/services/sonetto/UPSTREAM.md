# SonettoHere runtime

This directory contains the Python runtime adapted from SonettoHere for Studio Arona Client.

- Upstream: https://github.com/Miso2233/SonettoHere
- License: MIT, see `LICENSE`
- Imported: 2026-06-18

The upstream Vue frontend, documentation, tests, screenshots, setup scripts, and user-generated
data are intentionally excluded. Studio Arona provides the user interface and owns runtime data.
The repository-level `SonettoHere-main` directory is reference material only and is not used at
runtime.
