# 0528 优化总览

> 基于 `docs/0528mimo项目审查.md` 的发现，将修复工作拆分为 8 个独立 agent 任务。

## 执行顺序

```
Phase 1（无依赖，可并行）
├── 01-清理重复文件.md          ← 最先执行，消除干扰
├── 02-安全加固.md              ← CRITICAL 安全问题
└── 06-部署就绪.md              ← 基础设施修复

Phase 2（依赖 Phase 1 完成）
├── 03-前端框架升级.md          ← React 19 + Tailwind 4 + Vite 6
├── 04-OpenAPI合约补全.md       ← 补全规范 + 重新生成类型
└── 05-Bridge服务重构.md        ← 错误处理 + 内存泄漏 + TTS bug

Phase 3（依赖 Phase 2）
├── 07-Live2D迁移.md            ← pixi-live2d-display → Cubism SDK
└── 08-OpenClaw版本管理.md      ← 固定版本 + 更新通知
```

## 每个 agent 的标准流程

1. `git checkout -b <branch-name>` 从 main 创建分支
2. 按文档执行修改
3. 运行相关测试验证
4. 提交 commit（Conventional Commits 格式）
5. 报告完成状态

## 分支命名规范

| 任务 | 分支名 |
|------|--------|
| 清理重复文件 | `d/cleanup-duplicate-files` |
| 安全加固 | `d/security-hardening` |
| 前端框架升级 | `a/frontend-framework-upgrade` |
| OpenAPI 合约补全 | `d/openapi-spec-completion` |
| Bridge 服务重构 | `b/bridge-refactor` |
| 部署就绪 | `d/deployment-readiness` |
| Live2D 迁移 | `a/live2d-cubism-migration` |
| OpenClaw 版本管理 | `b/openclaw-version-pin` |
