## 验证步骤

1. `find . -name "* [0-9].*" -not -path "*/.venv/*" -not -path "*/node_modules/*" -not -path "*/__pycache__/*"` — 应返回空
2. `find . -type d -name "* [0-9]" -not -path "*/.venv/*"` — 应返回空
3. `pnpm install && pnpm --filter web exec tsc --noEmit` — 前端类型检查通过
4. `uv sync && uv run mypy services/` — Python 类型检查通过（如果配置了）
5. `pnpm --filter web exec vitest run` — 前端测试通过
6. `make dev` — 启动正常，所有页面可访问
