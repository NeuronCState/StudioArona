## E2E 全流程验证（2026-05-28 晚间）

### 测试范围
登录 → 创建会话 → 发送消息 → MiniMax M2.7 响应 → 数据库读写

### 发现并修复的问题

#### 1. Bridge memory.js UUID 校验缺失
**文件**: `services/agent/bridge/memory.js:128`
**问题**: `getRecentContext()` 没有检查 userId 是否为合法 UUID，非 UUID 用户（如测试用的 "test"）查询时 PostgreSQL 报错导致桥接服务崩溃
**修复**: 添加 `isValidUUID()` 校验，非 UUID 直接返回空上下文

#### 2. agent-pool.js 无限 warmup 循环
**文件**: `services/agent/bridge/agent-pool.js`
**问题**: `warmup()` 内部有 `setTimeout(() => this.warmup(), 5000)` 导致无限循环
**修复**: 移除 warmup() 内的自调用，改为在 execute() 完成后触发 warmup

#### 3. MiniMax 模型名称大小写
**文件**: `.env.local`
**问题**: `MINIMAX_MODEL=minimax-m2.7`（小写）导致 API 返回 2013 错误
**修复**: 改为 `MINIMAX_MODEL=MiniMax-M2.7`

#### 4. openclaw.json 工作区路径
**文件**: `services/agent/openclaw.json`
**问题**: `"workspace": "/app/workspace"` 是 Docker 路径，本地开发找不到目录
**修复**: 改为 `"workspace": "./workspace"`

#### 5. start.sh mktemp 失败
**文件**: `infra/scripts/start.sh`
**问题**: `/tmp/alembic-XXXXXX.log` 旧文件存在时 mktemp 失败
**修复**: 先 `rm -f /tmp/alembic-*.log`，X 位数改为 8 位

#### 6. .env.production 真实密钥
**文件**: `infra/compose/.env.production`
**问题**: 包含真实 MiniMax API key 和 JWT secret
**修复**: 全部替换为 `CHANGE_ME`
