# 03 — 前端框架升级

> 分支: `a/frontend-framework-upgrade`
> 预估: 8h | 角色: A | 依赖: 01-清理重复文件

## 目标

升级 React 18→19、Tailwind CSS 3→4、Vite 5→6，以及相关配套依赖。

## 风险评估

- **React 19**: 中等风险。`use()` hook、Server Components 是新增功能，不破坏现有代码。主要破坏点：`forwardRef` 不再需要、`ref` 作为 prop、`useContext` → `use(Context)`。
- **Tailwind 4**: 高风险。完全重写，配置方式从 JS 变为 CSS。所有 `tailwind.config.js` 需要迁移。
- **Vite 6**: 低风险。主要是 Environment API，对 SPA 无破坏。

## 执行顺序

### 3.1 Vite 5 → 6 [低风险，先做]

```bash
pnpm --filter web add -D vite@^6.0.0 @vitejs/plugin-react@^4.4.0
```

修改 `apps/web/vite.config.ts`（如有必要）。

验证：`pnpm --filter web exec vite build` 成功。

### 3.2 React 18 → 19 [中等风险]

```bash
pnpm --filter web add react@^19.0.0 react-dom@^19.0.0
pnpm --filter web add -D @types/react@^19.0.0 @types/react-dom@^19.0.0
```

**需要检查的破坏性变更：**

1. `forwardRef` — React 19 将 `ref` 作为普通 prop，`forwardRef` 不再必需。但旧写法仍兼容。
2. `useContext` → `use(Context)` — 旧 API 仍兼容。
3. `ReactDOM.render` → `createRoot` — 检查 `main.tsx`，应该已经用了 `createRoot`。
4. `propTypes` — 已移除。检查是否有组件用 `propTypes`。
5. `defaultProps` — 函数组件不再支持。检查是否有函数组件用 `defaultProps`。

**搜索需要修改的代码：**
```bash
grep -rn "forwardRef\|useContext\|propTypes\|defaultProps" apps/web/src/ --include="*.tsx" --include="*.ts"
```

**配套升级：**
```bash
pnpm --filter web add @tanstack/react-query@^5.60.0   # 已经是 5.x，确认兼容 React 19
pnpm --filter web add zustand@^5.0.0                   # 已经是 5.x，确认兼容
pnpm --filter web add framer-motion@^12.0.0            # 升级到 motion
pnpm --filter web add react-router-dom@^7.0.0          # 升级到 v7
```

**react-router-dom 6 → 7 注意事项：**
- v7 有框架模式，但 SPA 用法基本兼容
- `createBrowserRouter` 仍可用
- `useLoaderData` / `useActionData` 是新增功能

验证：`pnpm --filter web exec tsc --noEmit` 通过。

### 3.3 Tailwind CSS 3 → 4 [高风险，最后做]

**Tailwind v4 是完全重写，迁移步骤：**

1. 安装 v4：
```bash
pnpm --filter web add -D tailwindcss@^4.0.0 @tailwindcss/vite@^4.0.0
```

2. 删除 `tailwind.config.js` — v4 不再使用 JS 配置文件

3. 修改 `apps/web/src/index.css`（或入口 CSS 文件）：
```css
/* 旧 */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* 新 */
@import "tailwindcss";
```

4. 将 `tailwind.config.js` 中的自定义配置迁移到 CSS：
```css
@import "tailwindcss";

@theme {
  --color-primary: #3b82f6;
  /* 其他自定义颜色/字体/间距 */
}
```

5. 修改 `vite.config.ts`：
```typescript
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

6. 检查不兼容的类名变更：
   - `bg-opacity-*` → `bg-[color]/[opacity]`
   - `text-opacity-*` → `text-[color]/[opacity]`
   - `ring-opacity-*` → `ring-[color]/[opacity]`
   - `decoration-slice` → `box-decoration-slice`
   - `flex-grow-*` → `grow-*`
   - `flex-shrink-*` → `shrink-*`

7. 搜索受影响的类名：
```bash
grep -rn "bg-opacity\|text-opacity\|ring-opacity\|flex-grow\|flex-shrink\|decoration-slice" apps/web/src/ --include="*.tsx" --include="*.ts"
```

### 3.4 配套工具升级

```bash
pnpm --filter web add -D vitest@^3.0.0
```

## 验证步骤

1. `pnpm install` — 依赖安装成功
2. `pnpm --filter web exec tsc --noEmit` — 类型检查通过
3. `pnpm --filter web exec vite build` — 构建成功
4. `pnpm --filter web exec vitest run` — 测试通过
5. `pnpm --filter web exec playwright test` — E2E 测试通过（如环境允许）
6. 手动检查：所有页面渲染正常、样式无错位

## 风险缓解

- 如果 Tailwind 4 迁移问题太多，可以先跳过，保持 v3
- React 19 的兼容性较好，大部分 React 18 代码无需修改
- 如果 react-router-dom 7 有问题，可以保持 v6
