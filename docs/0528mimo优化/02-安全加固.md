## 任务清单

### 2.1 替换 python-jose → PyJWT [CRITICAL]

**文件**: `pyproject.toml`, `services/api-gateway/pyproject.toml`, `services/api-gateway/app/auth/jwt.py`

1. 在 `pyproject.toml` 和 `services/api-gateway/pyproject.toml` 中：
   - 移除 `python-jose[cryptography]>=3.3`
   - 添加 `PyJWT>=2.8`

2. 修改 `services/api-gateway/app/auth/jwt.py`：
   ```python
   # 旧
   from jose import jwt, JWTError, ExpiredSignatureError

   # 新
   import jwt as pyjwt
   from jwt.exceptions import PyJWTError, ExpiredSignatureError
   ```

3. 修改所有 `jwt.encode()` / `jwt.decode()` 调用：
   - `jwt.encode(payload, secret, algorithm=algo)` → `pyjwt.encode(payload, secret, algorithm=algo)`
   - `jwt.decode(token, secret, algorithms=[algo])` → `pyjwt.decode(token, secret, algorithms=[algo])`
   - `JWTError` → `PyJWTError`

4. 修改 `services/api-gateway/app/auth/deps.py` 中的异常捕获

5. `uv sync` 更新 lock 文件

### 2.2 强制 JWT secret 配置 [CRITICAL]

**文件**: `services/api-gateway/app/core/config.py`

```python
# 旧
JWT_SECRET: str = "dev-only-replace-me"

# 新 — 空默认 + 启动时检查
JWT_SECRET: str = ""
```

在 `services/api-gateway/app/main.py` 的 startup 事件中添加：
```python
@app.on_event("startup")
async def check_config():
    if not settings.JWT_SECRET:
        raise RuntimeError("JWT_SECRET must be set. Aborting startup.")
```

### 2.4 实现 logout（Redis token 黑名单）[HIGH]

**文件**: `services/api-gateway/app/api/auth.py`

1. 在 `auth.py` 中注入 Redis 依赖
2. logout 端点实现：
   ```python
   @router.post("/logout", status_code=204)
   async def logout(
       response: Response,
       current_user: User = Depends(get_current_user),
       redis: Redis = Depends(get_redis),
   ):
       # 将当前 access token 的 jti 加入黑名单，TTL = token 剩余有效期
       # 清除 CSRF cookie
       response.delete_cookie(CSRF_COOKIE_NAME)
   ```
3. 在 `deps.py` 的 `get_current_user` 中检查 token 是否在黑名单中

### 2.5 限流器 fail-open → fail-closed + 日志 [HIGH]

**文件**: `services/api-gateway/app/middleware/rate_limit.py`

```python
# 旧
except Exception:
    return await call_next(request)

# 新
except Exception as e:
    logger.warning("Redis unavailable, rate limiting failed closed", error=str(e))
    return JSONResponse(
        status_code=503,
        content={"detail": "Service temporarily unavailable"},
    )
```

### 2.6 Internal memory API 加 localhost 保护 [HIGH]

**文件**: `services/api-gateway/app/internal/memory_api.py`

在每个端点添加 localhost 检查（参考 `events.py` 的实现）：
```python
async def _require_localhost(request: Request):
    if request.client and request.client.host not in ("127.0.0.1", "::1"):
        raise HTTPException(status_code=403, detail="Internal endpoint")
```

### 2.7 CSRF cookie 加 secure 标志 [MEDIUM]

**文件**: `services/api-gateway/app/api/auth.py`

```python
# 旧
response.set_cookie(key=CSRF_COOKIE_NAME, value=csrf_token, httponly=False, samesite="strict", max_age=3600)

# 新
response.set_cookie(
    key=CSRF_COOKIE_NAME, value=csrf_token,
    httponly=False, samesite="strict", max_age=3600,
    secure=settings.ENVIRONMENT == "production",
)
```
