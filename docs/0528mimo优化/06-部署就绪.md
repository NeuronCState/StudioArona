### 6.4 深化 Health Check [HIGH]

**文件**: `services/api-gateway/app/api/health.py`

```python
@router.get("/health")
async def health(db: AsyncSession = Depends(get_db), redis: Redis = Depends(get_redis)):
    checks = {}
    try:
        await db.execute(text("SELECT 1"))
        checks["postgres"] = "ok"
    except Exception:
        checks["postgres"] = "error"

    try:
        await redis.ping()
        checks["redis"] = "ok"
    except Exception:
        checks["redis"] = "error"

    status = "ok" if all(v == "ok" for v in checks.values()) else "degraded"
    return {"status": status, "checks": checks}
```

### 6.9 Entrypoint 等待超时 [MEDIUM]

**文件**: `infra/docker/scripts/entrypoint.sh`

```bash
# 旧 — 无限循环
while ! pg_isready ...

# 新 — 最多重试 30 次（60 秒）
MAX_RETRIES=30
RETRY=0
while ! pg_isready ...; do
  RETRY=$((RETRY + 1))
  if [ $RETRY -ge $MAX_RETRIES ]; then
    echo "ERROR: PostgreSQL not ready after ${MAX_RETRIES} retries"
    exit 1
  fi
  sleep 2
done
```
