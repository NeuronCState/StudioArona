## 整合要点

### 1. 去重与清理
当前项目中存在大量重复文件（如 `assets 2`、`script 3.js`、`.venv/bin 2` 等），发布前必须执行：
- 删除所有带数字后缀的重复目录/文件
- 统一 `.venv` 为单一虚拟环境
- 合并散落在根目录的截图（语音按钮 *.PNG）到对应包文档中

### 2. Monorepo 架构
采用 `packages/` 管理前端组件，每个组件独立 `package.json`，支持：
- 独立版本发布
- 按需引入
- 独立测试与构建

### 3. 前后端分离
- `agent/` → Node.js AI Agent 服务
- `backend/` → Python FastAPI 业务后端
- `packages/` → 纯前端组件，无后端依赖

### 4. 资源归类
| 原始位置 | 目标位置 |
|---------|---------|
| `CNAronaPlana/assets/` | `packages/live2d-arona/assets/spine/` |
| `阿洛娜4.6版本/` | `packages/live2d-arona/assets/live2d/` |
| `白天黑夜切换按钮4.0/` | `packages/theme-toggle/` |
| `语音按钮 *.PNG` | `packages/voice-button/docs/` |
| `docs/` | `docs/` (保留) |
