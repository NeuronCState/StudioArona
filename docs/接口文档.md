# 串口通信协议接口文档 v1.4

**固件版本**：openCF1 v1.4 **通信接口**：蓝牙 BLE (UART3, PB10/PB11) **波特率**：115200, 8N1 **舵机类型**：总线舵机 (UART4 转发) / PWM 舵机 **存储介质**：W25Q64 Flash + EEPROM

> ⚠️ **重要提示**：所有回复文字均从 **UART1 (PA9/PA10)** 发出。UART3 蓝牙端**收不到任何回复**。舵机动作本身会正常执行，仅无文字反馈。如需查看回复，请用 USB 转 TTL 模块连接 UART1。

## 二、系统命令类（`$` 开头，`!` 结尾）

### 2.1 设备应答测试

```
指令：$DRS!
参数：无
回复：UART1: "hello word!"
说明：验证串口通信是否正常
```

### 2.2 获取应答信号

```
指令：$GETA!
参数：无
回复：UART1: "AAA"
说明：简易握手测试
```

### 2.3 所有舵机急停

```
指令：$DST!
参数：无
回复：无 (向总线发送 #255PDST!)
说明：立即停止所有舵机，AI 模式清零
```

### 2.4 指定舵机急停

```
指令：$DST:x!
参数：x = 舵机 ID (0~255)
示例：$DST:3!
回复：无 (向总线发送 #003PDST!)
说明：停止指定 ID 的舵机
```

### 2.5 单片机软复位

```
指令：$RST!
参数：无
回复：无 (系统直接重启)
说明：关闭中断后触发 NVIC_SystemReset()
```

### 2.6 执行单个动作组

```
指令：$DGS:x!
参数：x = 动作组序号
示例：$DGS:5!
回复：无 (动作执行完毕无通知)
说明：从 W25Q64 Flash 读取第 x 组动作并执行
```

### 2.7 执行动作组序列（循环）

```
指令：$DGT:x-y,z!
参数：x = 起始组号, y = 终止组号, z = 循环次数 (0 = 无限循环)
示例：$DGT:1-10,3!
回复：UART1: "@GroupDone!" (全部循环结束后)
说明：依次执行 x~y 组动作，重复 z 次
```

### 2.8 检查动作组存储状态

```
指令：$CGP:x-y!
参数：x = 起始组号, y = 终止组号
示例：$CGP:1-5!
回复：UART1: (各组的 16 进制存储标志)
说明：检查指定范围内的动作组是否已存储
```

### 2.9 所有舵机复位

```
指令：$DJR!
参数：无
回复：无 (所有舵机 PWM 归中位 1500)
说明：将所有舵机复位到中位位置
```

### 2.10 运动学逆解控制（直角坐标）

```
指令：$KMS:x,y,z,time!
参数：x,y,z = 末端坐标 (mm), time = 运行时间 (ms)
示例：$KMS:50,80,30,1000!
回复：UART1: "Can't find best pos!!!" (仅求解失败时)
说明：通过运动学逆解计算关节角度并执行，详见第三章
```

### 2.11 智能停止

```
指令：$SMART_STOP!
参数：无
回复：UART1: "@OK!"
说明：停止所有舵机后，6/7 号舵机回中位
```

### 2.12 蜂鸣器

```
指令：$BEEP!
参数：无
回复：无
说明：蜂鸣器响 100ms
```

## 三、舵机控制类（`#` 开头，`!` 结尾）

### 3.1 单舵机角度控制

```
格式：#xxxPyyyyTzzzz!
参数：
  xxx  = 舵机 ID (3 位数字, 000~255)
  yyyy = PWM 脉宽值 (4 位数字, 通常 500~2500, 中位 1500)
  zzzz = 运行时间 (4 位数字, 单位 ms)
示例：#003P1500T1000!
      → 3 号舵机转到 1500 脉宽，耗时 1000ms
回复：无 (指令转发至 UART1/UART4/总线舵机)
```

### 3.2 多舵机联动（大括号包裹）

```
格式：{#000P1500T1000!#001P2000T500!#002P1200T800!}
参数：大括号 { } 内可包含多个单舵机指令
      结束符为 }
回复：无
说明：所有舵机同时执行各自的 PWM 和时间参数
```

### 3.3 舵机偏置校准

```
格式：#xxxPSCK±yyy!
参数：
  xxx = 舵机 ID (3 位)
  ±   = + 或 -
  yyy = 偏置值 (3 位, 范围 0~200)
示例：#003PSCK+050!   → 3 号舵机偏置 +50
      #005PSCK-030!   → 5 号舵机偏置 -30
回复：无 (偏置值存入 EEPROM，重启后保留)
```

### 3.4 总线舵机停止

```
格式：#xxxPDST!
参数：xxx = 舵机 ID (255 表示全部)
示例：#003PDST!   → 停止 3 号舵机
      #255PDST!   → 停止所有总线舵机
回复：无
```

## 四、动作组存储类（`<` 开头，`>` 结尾）

### 4.1 存储动作组

```
格式：<Gxxxx#000P1500T1000!#001P2000T500!...>
参数：
  xxxx = 动作组序号 (4 位数字)
  > 之前可以有任意多个 #舵机指令
示例：<G0001#000P1500T1000!#001P2000T500!#002P1200T500!>
      → 将动作存储到第 1 组，保存到 W25Q64 Flash
回复：UART1: "A" (存储成功)
说明：存储后可通过 $DGS:1! 调用
```

### 4.2 设置开机自启动动作

```
格式：<$#000P1500T1000!#001P2000T500!>
参数：$ 后面跟舵机指令，以 > 结尾
示例：<$#000P1500T1000!#001P2000T500!>
回复：UART1: "@SET PRE_CMD OK!"
说明：上电后自动执行，存储在 EEPROM
```

### 4.3 删除开机自启动动作

```
格式：<$!>
参数：无
回复：UART1: "@CLEAR PRE_CMD OK!"
说明：清除上电自动执行的动作
```

## 五、运动学逆解控制详解 ($KMS)

### 5.1 坐标系定义

```
原点 O：底座旋转中心正下方的地面点

X 轴：水平面内，机械臂初始化姿态下的左右方向
      正值 → 右侧（从后方看）
      负值 → 左侧

Y 轴：水平面内，机械臂正前方方向
      正值 → 前方
      负值 → 后方（不可达）

Z 轴：垂直向上方向
      正值 → 地面以上高度
      Z = 0 → 地面
```

#### 坐标平面俯视图

```
              Y+ (正前方 0°)
               ↑
               |
               |  ★ 目标点 (x=50, y=80)
               |  /
               | /
               |/
               +-------→ X+ (右侧)
              / O
             /
            /
           Z+ 垂直纸面向外 (上方)
```

#### 直角坐标与关节映射

底盘旋转角 θ₆ 由 XY 平面投影计算：

```
θ₆ = atan(x / y) × 270° / π
```

### 5.4 控制算法流程

```
┌──────────────┐
│ 接收 $KMS    │
│ x, y, z, time│
└──────┬───────┘
       ↓
┌──────────────────┐
│ α 从 -25° 到 -65°│ ← 搜索最优爪子角度
│ 步进 -1°         │
└──────┬───────────┘
       ↓
┌─────────────────────────┐
│ kinematics_analysis()   │ ← 对每个 α 调用逆解
│ 返回 0 = 有解           │
│ 返回 1~7 = 无解         │
└──────┬──────────────────┘
       ↓ 有解时
┌──────────────────┐
│ 发送 4 路舵机PWM  │ ← 映射到 1500±2000 脉宽
│ 执行 time 时长    │
└──────────────────┘
```

## 七、数据包解析流程

```
UART 中断接收 → uart_data_parse(buf, num)
    ↓ 存入全局缓冲区 uart_receive_buf
app_uart_run() 定时轮询 (1ms)
    ↓ 取出完整帧
parse_action(cmd)     → 解析 # 开头指令 (舵机控制)
parse_cmd(cmd)        → 解析 $ 开头指令 (系统命令)
save_action(cmd, pos) → 解析 < 开头指令 (存储动作组)
    ↓
执行对应操作 / 回复 UART1
```

## 八、注意事项

1.  **UART3 蓝牙无回复**：所有回复均从 UART1 发出。
    
2.  **Y 坐标 ≥ 0**：$KMS 的目标点 Y 坐标不能为负（不能指定底座正后方位置）
    
3.  **time 单位是毫秒**：舵机指令的 T 参数建议 ≥ 500 ms
    
4.  **坐标单位为 mm**：$KMS 输入前须转换为毫米
    
5.  **偏置值重启保留**：舵机偏置校准存入 EEPROM，断电不丢失
    
6.  **动作组存入 Flash**：通过 `<Gxxxx...>` 存储的动作组需调用 `$DGS:x!` 执行
