## 1. 红线 · 必读必守

### 1.1 OpenClaw 安全护栏（最高优先级）

**用户的明确要求**：阿洛娜不能操作本项目源代码 / 部署文件，不能跨用户访问内容。

| 边界 | 规则 |
|---|---|
| ❌ 禁止 | 读 / 写 `apps/`、`services/`、`packages/`、`infra/`、`docs/` 下任何文件 |
| ❌ 禁止 | 调用 `subprocess`、`os.system`、宿主 shell exec、`docker`、`git`、宿主端口扫描 |
| ❌ 禁止 | 跨用户数据访问（任何 skill handler 不携带 `ctx.user_id` 即拒绝） |
| ❌ 禁止 | 跨用户 VM 访问（VM 控制必须 `WHERE vm.user_id == ctx.user_id`） |
| ❌ 禁止 | DDL（`CREATE` / `ALTER` / `DROP`）、原始 SQL 拼接、`exec()` |
| ❌ 禁止 | 任意 outbound HTTP；仅允许：白名单 RSS 源、Home Assistant 局域网、已注册 webhook |
| ✅ 允许 | 仅通过 `packages/skills/<name>/handler.py` 注册的工具间接调用 |
| ✅ 允许 | 自己的 workspace（`services/agent/workspace/*.md`）+ 当前用户的 memory |
| ✅ 允许 | **当前 user_id 名下** VM 的：状态、控制台输出 tail、guest agent exec（**白名单命令** + 用户确认 + 超时 + 输出截断） |

**新增能力 · VM 控制台读 + 受限 exec（B 在 M5.2 落地）**：
- `vms.console.tail` — 读取 VM 串口日志最近 N 行（只读）
- `vms.console.exec` — 通过 `qemu-guest-agent` 执行**白名单**命令（受时间 / 输出 / 路径限制）
- 详见 `02_工程师B_后端数据与OpenClaw.md` §4

### 1.2 Live2D 授权
用户已确认**完全个人使用**，无 Live2D Cubism SDK 商用授权风险。模型路径：`阿洛娜4.6版本/阿洛娜4.6/`。

### 4.2 新增 `ui_action` 类型（本阶段引入）

```jsonc
// LLM 命令前端做的视觉响应
{ "type": "live2d.play_motion", "group": "Idle", "name": "idle" }
{ "type": "live2d.set_expression", "name": "星星眼" }
{ "type": "live2d.set_emotion", "emotion": "happy" }   // 复合：自动选 motion + expression
{ "type": "live2d.lipsync_audio", "audio_url": "..." }
{ "type": "theme.switch", "mode": "arona" | "studio" }  // LLM 主动建议切换
{ "type": "scene.set_time", "time": "day" | "dusk" | "night" }
{ "type": "scene.set_weather", "weather": "clear" | "rain" | "snow" }
{ "type": "vm.console_followup", "vm_id": "...", "tail_lines": 50 }  // VM 输出回显
```

### 4.3 信号链
```
用户 → 前端 chat → POST /api/chat/sessions/:id/messages
  → api-gateway → agent (OpenClaw)
  → LLM 流式输出（含尾标签 [emotion:..] [expr:..] [motion:..]）
  → agent 解析 → SSE：token / tool_call / tool_result / ui_action / done
  → 前端 sse-client 分发
  → ui-actions.ts 执行 handler
  → Live2D（A）+ Toast（C）+ 数据刷新（A）
```

### 4.4 LLM 情绪标签
LLM 在回复末尾追加（agent 端解析后剥离再发给前端）：
```
[motion:idle] [expr:星星眼] [emotion:happy] [scene:dusk]
```

可用 expression（来自模型实际文件）：哭哭、嘴变形、嘴变形2、圈圈、墨镜、抓抓、指纹锁、挤眼、星星眼、流口水、牛奶、猫猫、生气、眯眼、脸红、螺旋、阴脸
可用 motion group：Idle（含 idle、水饺）

参考 [Open-LLM-VTuber 的 live2d_model.py](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber) —— **标签解析 + 表情/动作映射** 的设计思路（不要直接拷贝代码，参照思路本地实现）。

## 6. 风险与缓解

| 风险 | 缓解 | 责任 |
|---|---|---|
| Live2D `model3.json` 的 `EyeBlink/LipSync.Ids` 为空 | A 加载时根据 `cdi3.json` 反推参数 ID | A |
| Three.js + Live2D 同页 GPU 吃紧 | 双 canvas 分层；fallback 关 3D 仅留 Live2D | A + C |
| OpenClaw sandbox 影响开发调试 | dev 模式 `--unsafe-relax` 开关（仅本机） | B |
| BA 教室 `.blend` 不能进浏览器 | A 用 Blender CLI 离线导出 `.glb` + gltf-transform 优化 | A |
| Cubism SDK 体积大 | Cubism Core 走 CDN runtime，不进 bundle | A + C |
| WebGL 替换后旧浏览器无法显示 | 提供 `<noscript>` 渐变兜底 + `WEBGL.isWebGLAvailable()` 检测 | C |
| VM exec 危险 | 命令白名单 + 用户确认 + 10s 超时 + 1MB 输出截断 + audit | B |
| 三人同改 `tokens.css` 冲突 | C 主笔，A 评审；颜色 token 与动效 token 分文件 | A + C |
