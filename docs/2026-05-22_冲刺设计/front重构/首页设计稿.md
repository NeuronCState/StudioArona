## 动画体系

### 1. 页面进入动画

| 属性 | 值 |
|------|-----|
| 动画名 | `home-enter` |
| 目标元素 | 整个页面容器 |
| 持续时间 | 300ms |
| 缓动 | `cubic-bezier(0, 0, 0.2, 1)` |
| 起始 | opacity: 0, transform: translateY(12px) |
| 结束 | opacity: 1, transform: translateY(0) |

```
时间轴:
  0ms    ████████████████████ 300ms
  opacity: 0 ────────────── opacity: 1
  Y: +12px ──────────────── Y: 0
```

### 2. 磁贴出现动画（Staggered Entrance）

每个磁贴有独立延时的入场动画，形成**从左到右、从上到下**的波浪感。

| 磁贴 | 延时 | 动画名 | 效果 |
|------|------|--------|------|
| Schedule Tile | 0ms | `tile-enter-1` | 从左滑入 + 淡入 |
| Weather Tile | 80ms | `tile-enter-2` | 从右滑入 + 淡入 |
| System Tile | 160ms | `tile-enter-3` | 从左下升起 + 淡入 |
| RSS Tile | 240ms | `tile-enter-4` | 从右下升起 + 淡入 |
| Quick Chat | 350ms | `tile-enter-5` | 从底部升起 + 淡入 |

**磁贴入场动画规格**：

```css
@keyframes tile-enter-1 {
  0% {
    opacity: 0;
    transform: translateX(-24px) translateY(4px) scale(0.97);
  }
  100% {
    opacity: 1;
    transform: translateX(0) translateY(0) scale(1);
  }
}

/* tile-enter-2: translateX(+24px) 从右侧滑入 */
/* tile-enter-3: translateY(16px) 从下方升起 */
/* tile-enter-4: translateX(+16px) translateY(16px) 从右下升起 */
/* tile-enter-5: translateY(24px) 从底部升起 */
```

所有磁贴入场动画：
- 持续时间：400ms
- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)` (spring-like ease-out-back)
- 结束时 scale: 1, opacity: 1

### 3. 磁贴浮动动画（Hover Float）

磁贴在 hover 时向上浮动并增加阴影深度。

```css
.tile {
  transition:
    transform 250ms cubic-bezier(0, 0, 0.2, 1),
    box-shadow 250ms cubic-bezier(0, 0, 0.2, 1),
    border-color 250ms cubic-bezier(0, 0, 0.2, 1);
}

.tile:hover {
  transform: translateY(-4px);
  box-shadow:
    0 4px 6px rgba(0, 0, 0, 0.06),
    0 10px 20px rgba(0, 0, 0, 0.08);
  border-color: var(--color-accent);
}
```

| 状态 | Y 偏移 | 阴影 | 边框 |
|------|--------|------|------|
| 默认 | 0 | `shadow-sm` (0 1px 3px 6% + 0 1px 2px 4%) | `#F5F5F4` |
| Hover | -4px | `shadow-lg` (0 10px 20px 8%) | `#D97706` (琥珀) |

### 4. 磁贴内容动画

#### 4a. Schedule 列表项

```css
@keyframes schedule-item-enter {
  0% {
    opacity: 0;
    transform: translateX(-12px);
  }
  100% {
    opacity: 1;
    transform: translateX(0);
  }
}
```

每个列表项延时 60ms：
- Item 1: 100ms 后开始
- Item 2: 160ms
- Item 3: 220ms

#### 4b. System 进度条

```css
@keyframes bar-fill {
  from { transform: scaleX(0); }
  to   { transform: scaleX(var(--bar-pct)); }
}
```

进度条依次填充：
- CPU: 0ms 开始，600ms 填满
- Memory: 120ms 开始
- Disk: 240ms 开始
- Network: 360ms 开始

#### 4c. Weather 图标

```css
@keyframes weather-float {
  0%, 100% { transform: translateY(0) scale(1); }
  50%      { transform: translateY(-3px) scale(1.05); }
}

.weather-icon {
  animation: weather-float 3s ease-in-out infinite;
}
```

#### 4d. RSS 条目

从右侧淡入，每个延时 80ms。

┌──────────────────────────────────────────────────────┐

| 入场动画 | 最晚出现 (350ms delay)，从下方升起 24px |

## 动画时间线总览

```
t=0ms                页面容器开始 fade-in + Y 上移
t=0ms                问候语开始 fade-in + Y 上移
t=100ms              日期文字 fade-in
t=200ms              Schedule Tile 从左滑入 (400ms dur)
t=280ms              Weather Tile 从右滑入 (400ms dur)
t=360ms              System Tile 从左下升起 (400ms dur)
   t=360ms             CPU 进度条开始填充 (600ms)
   t=480ms             Memory 进度条开始填充
   t=600ms             Disk 进度条开始填充
   t=720ms             Network 进度条开始填充
t=440ms              RSS Tile 从右下升起 (400ms dur)
   t=540ms             RSS Item 1 淡入
   t=620ms             RSS Item 2 淡入
   t=700ms             RSS Item 3 淡入
   t=780ms             RSS Item 4 淡入
t=550ms              Quick Chat 从底部升起 (400ms dur)
t=950ms              全部入场动画完成
```

总入场时长：约 **950ms**，有层次但不拖沓。

## 磁贴点击行为

| 磁贴 | 点击行为 |
|------|----------|
| Schedule Tile（空白区） | 导航至 `/schedule` |
| Weather Tile | 导航至 `/weather` 或刷新天气 |
| System Tile | 导航至 `/system` |
| RSS Tile | 导航至 `/feeds` |
| Quick Chat Bar | 创建会话并导航至 `/chat` |
| 磁贴右上角 `>` | 同上，导航至对应页面 |
