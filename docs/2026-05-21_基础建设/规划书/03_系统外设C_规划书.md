## 5. 抽象层接口（铁律）

每个外设/系统资源都有抽象基类，Mac / Linux 实现各一份，env 切换。

### 5.1 摄像头

```python
class CameraSource(Protocol):
    async def open(self, device: int | str) -> None: ...
    async def read(self) -> Frame: ...
    async def close(self) -> None: ...
    @property
    def fps(self) -> float: ...
    @property
    def resolution(self) -> tuple[int, int]: ...
```

- **Mac**：用 OpenCV `VideoCapture(0)` 取 FaceTime 摄像头（首次需授权）。
- **Linux**：用 V4L2 设备路径。

### 5.2 串口

```python
class SerialPort(Protocol):
    async def open(self, port: str, baud: int) -> None: ...
    async def write(self, payload: bytes) -> None: ...
    async def read(self, n: int, timeout_ms: int) -> bytes: ...
```

- **Mac mock**：`write` 把 payload 解析后打 structlog；`read` 返回固定 ACK。
- **Linux**：pyserial。
- **协议（与张洪瀚组对齐）**：暂用占位帧
  ```
  [0xAA][len][cmd][payload...][crc16]
  ```
  cmd=0x01 设置目标偏移，payload 为 `int16 dx, int16 dy, uint16 depth_mm`。
  W2 末与硬件组开会冻结。冻结后写到 `docs/adr/0003-serial-protocol.md`。

### 5.3 屏幕方向

```python
class ScreenOrientation(Protocol):
    async def set(self, orientation: Literal["landscape","portrait"]) -> None: ...
    async def get(self) -> str: ...
```

- **Mac mock**：no-op + 推 WS 事件 `screen_changed`。
- **Linux**：调 `wlr-randr --output ... --transform 90`。

### 5.4 硬件指标

```python
class MetricsProvider(Protocol):
    async def snapshot(self) -> SystemMetrics: ...
```

`SystemMetrics`（pydantic 模型，进 `packages/contracts`）：

```python
class GPU(BaseModel):
    name: str; mem_total_mb: int; mem_used_mb: int
    util_pct: float; temp_c: float; processes: list[GpuProc]

class CPUCore(BaseModel):
    index: int; util_pct: float; freq_mhz: float

class SystemMetrics(BaseModel):
    ts: datetime
    cpu_cores: list[CPUCore]
    mem_total_mb: int; mem_used_mb: int
    disks: list[DiskUsage]
    gpus: list[GPU]
    training_jobs: list[TrainingJob]
```

- **Mac**：cpu/mem/disks 真，gpus 假（固定 V100 + 围绕 50% 抖动），training_jobs 假。
- **Linux**：psutil + nvidia-smi 真，training_jobs 通过扫 GPU 进程 + 命名规则识别。

### 5.5 VM

```python
class VMBackend(Protocol):
    async def list(self, owner_id: str | None) -> list[VM]: ...
    async def create(self, spec: VMSpec, owner_id: str) -> VM: ...
    async def start(self, id: str) -> None: ...
    async def stop(self, id: str) -> None: ...
    async def destroy(self, id: str) -> None: ...
    async def upload(self, id: str, src_path: str, dst_path: str) -> None: ...
    async def ssh_endpoint(self, id: str) -> SshEndpoint: ...
```

- **Mac mock**：内存状态机 + 异步状态转移（creating → running 模拟 8s）。upload 把文件存 `tmp/vm-uploads/`。
- **Linux**：VBoxManage 命令行 + ttyd。

### 5.6 网络

```python
class NetworkScanner(Protocol):
    async def scan(self) -> list[NetworkDevice]: ...
    async def device_info(self, ip: str) -> DeviceDetail: ...
```

- **Mac mock**：返回 12 台假设备（覆盖 PC / VM / 路由 / 打印机），随机几台 offline。
- **Linux**：nmap ping scan + ARP 表 + SNMP 询问交换机端口（要权限）。

## 6. 人脸识别与跟踪

### 6.1 流水线（Mac 跑通）

```
摄像头帧 → YOLOE-26s-seg 检测 → 取最近最大人脸框
       → 中心坐标 + 框面积 → 偏移量 + 深度估计
       → 一阶低通滤波（α=0.6）→ P-control（kp=0.04）
       → SerialPort.write(cmd=0x01, dx, dy, depth)
       → 同时 WS 推 face_track 给前端
```

人脸识别（认人）：
- 注册：每位成员 5–10 张正面 → ArcFace 提 embedding 存 `user_face_embeddings`。
- 识别：检测到的脸做 embedding，余弦相似度 ≥ 0.62 视为匹配；否则视为陌生人。
- 匹配 → 推 `wake` 事件（带 user_id + confidence）。

### 6.2 唤醒/离开判定

- **唤醒**：连续 10 帧（约 0.4s）检测到同一身份 → 推 `wake`，进入 tracking 状态。
- **离开**：连续 30 帧（约 1.2s）无人脸 → 推 `leave`。
- 抗抖：滑窗投票，避免一帧丢失就认为离开。

### 6.3 性能目标
- Mac M 系列：≥ 15 fps（CPU/MPS 推理）。
- Linux V100：≥ 30 fps（CUDA）。

### 6.4 隐私
- 摄像头帧**不落盘**；只有特征向量入库。
- 录入流程必须用户主动确认；可单独删除自己 embedding。

## 9. 测试规范

### 9.1 单元测试（pytest）

- 摄像头：用 `tests/C/fixtures/sample_frames/*.jpg` 灌入 fake CameraSource，断言检测器输出。
- 跟踪滤波：给一组带噪声轨迹，断言输出轨迹平滑度（导数 L2 < 阈值）。
- 串口 mock：断言打包字节符合协议规范（含 CRC）。
- VM 状态机：断言 create → running 的状态序列与时间戳。
- Metrics Mac 实现：断言 GPU 字段为 mock，但 mem/cpu 字段范围合理。

```bash
uv run pytest tests/C          # C 全量单测
uv run pytest tests/C -k "face"
uv run pytest --cov=services/perception
```

覆盖率门槛：core/* ≥ 85%，整体 ≥ 75%。

### 9.2 集成测试

- **假摄像头视频**：`tests/C/fixtures/face_walkin.mp4`（一个人走近 → 离开 → 另一人进入）→ 断言 wake / leave / wake 事件序列。
- **协议回环**：写入串口 mock → mock 解析回 → 断言一致。
- **VM 端到端**：发 create → 轮询直到 running → upload 一个小文件 → destroy。

### 9.3 视觉模型回归

- 维护 `tests/C/model_regression/`：100+ 张工作室成员脸 + 100+ 张干扰脸（随机互联网人脸）。
- 每周一跑：识别率 ≥ 95%，误识 ≤ 1%。掉超过 2 个百分点开 issue。

### 9.4 性能基线

```bash
uv run python tests/C/perf/face_fps.py        # 目标 ≥ 15 fps Mac
uv run python tests/C/perf/metrics_latency.py # 目标 < 100ms snapshot
```

### 9.5 安全 / 边界
- 摄像头权限被拒：服务降级到"无摄像头"模式，不崩。
- VM destroy：必须二次确认 + 操作审计日志。
- 上传压缩包：限大小 / 限类型 / 解压前扫描（zip-slip 防护）。

## 10. 开发规范

### 10.1 代码风格
- Ruff + mypy strict + pyright（与 B 一致）。
- OpenCV / numpy 操作集中在 `core/face/`，不允许在 api / workers 层写矩阵。
- 所有 IO 操作 async；CPU 密集（推理）用 `asyncio.to_thread` + 进程池。

### 10.2 抽象层使用规则
- **绝对不允许**在 api / workers 里 import Mac 或 Linux 具体实现。只 import base。
- 实现的选择由 `app/core/factory.py` 根据 env 决定。
- 这条是 Mac→Linux 无缝迁移的命脉，PR review 重点检查。

### 10.3 配置
```
PERCEPTION_PLATFORM=mac      # mac | linux
PERCEPTION_CAMERA_DEVICE=0
PERCEPTION_FACE_THRESHOLD=0.62
PERCEPTION_TRACK_FPS=15
PERCEPTION_SERIAL_PORT=mock  # mock | /dev/ttyUSB0
PERCEPTION_VM_BACKEND=mock   # mock | vbox
```
> **注意**：不叫 `MOCK_FACE_CAMERA_DEVICE`。env 变量名与 `.env.example` 完全一致。

### 10.4 日志
- structlog JSON。字段：`service=perception`, `subsystem=face|serial|vm|...`, `latency_ms`, `event`。
- 不打人脸图像；只打 user_id + confidence。
