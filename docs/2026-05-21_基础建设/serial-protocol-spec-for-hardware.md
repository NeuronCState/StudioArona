## 1. 概述

Studio Javis 主机通过串口向机械臂发送**目标跟踪偏移指令**，控制机械臂云台跟随人脸转动。

```
┌─────────────┐    USB-TTL 串口    ┌─────────────┐
│  Javis 主机  │ ───────────────→ │   机械臂MCU  │
│  (Python)    │    115200 baud    │  (STM32等)   │
└─────────────┘                    └─────────────┘
```

**数据流方向**：主机 → 机械臂（单向下发，暂无回传）

## 3. 帧格式

每一帧的结构如下：

```
┌──────┬──────┬──────┬─────────────┬──────────┐
│ HEAD │ LEN  │ CMD  │   PAYLOAD   │   CRC    │
│ 0xAA │  1B  │  1B  │  0~255 B    │   2B     │
└──────┴──────┴──────┴─────────────┴──────────┘
```

### 3.1 字段说明

| 字段 | 长度 | 值 | 说明 |
|------|------|-----|------|
| HEAD | 1 字节 | `0xAA` | 帧起始标识，固定值 |
| LEN | 1 字节 | 2~257 | payload 长度 + 2（CMD + CRC 各占 1/2 字节） |
| CMD | 1 字节 | 见下表 | 命令类型 |
| PAYLOAD | 0~255 字节 | 变长 | 命令参数 |
| CRC | 2 字节 | CRC16 | 校验码，覆盖 HEAD 到 PAYLOAD 的所有字节 |

### 3.2 字节序

**所有多字节整数均为小端序（Little-Endian）**。

例如 int16 值 `100`（0x0064）在字节流中为：`64 00`

### 3.3 CRC16 算法

- **算法**：CRC-CCITT
- **初始值**：`0xFFFF`
- **多项式**：`0x1021`
- **输入**：HEAD 到 PAYLOAD 的所有字节（不含 CRC 本身）
- **输出**：2 字节，小端序

**Python 参考实现**：

```python
def crc16_ccitt(data: bytes) -> int:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte << 8
        for _ in range(8):
            if crc & 0x8000:
                crc = (crc << 1) ^ 0x1021
            else:
                crc <<= 1
            crc &= 0xFFFF
    return crc
```

**C 参考实现**：

```c
uint16_t crc16_ccitt(const uint8_t *data, size_t len) {
    uint16_t crc = 0xFFFF;
    for (size_t i = 0; i < len; i++) {
        crc ^= (uint16_t)data[i] << 8;
        for (int j = 0; j < 8; j++) {
            if (crc & 0x8000)
                crc = (crc << 1) ^ 0x1021;
            else
                crc <<= 1;
        }
    }
    return crc;
}
```

## 4. 命令定义

### CMD 0x01 — 设置目标偏移

控制机械臂云台转向指定方向。

| 字段 | 类型 | 偏移 | 长度 | 说明 |
|------|------|------|------|------|
| dx | int16 | 0 | 2 字节 | 水平偏移（正值=向右，负值=向左） |
| dy | int16 | 2 | 2 字节 | 垂直偏移（正值=向下，负值=向上） |
| depth_mm | uint16 | 4 | 2 字节 | 目标距离（毫米） |

**payload 长度**：6 字节
**LEN 字段值**：8（6 payload + 2 CRC）

#### 偏移量含义

- `dx` / `dy` 是经过 PID 控制计算后的**输出量**，不是像素坐标
- 单位可由机械臂端自行定义（建议：0.01 度 或 步进电机步数）
- `depth_mm` 是距离估计，用于机械臂做力度/速度适配（可选使用）

#### 值域

| 字段 | 最小值 | 最大值 | 说明 |
|------|--------|--------|------|
| dx | -32768 | 32767 | int16 |
| dy | -32768 | 32767 | int16 |
| depth_mm | 0 | 65535 | uint16，单位毫米 |

#### 示例

**目标：dx=100, dy=-50, depth=1200mm**

```
AA 08 01 64 00 CE FF B8 04 xx xx
│  │  │  └───┘  └───┘  └───┘  └── CRC16
│  │  │  dx=100  dy=-50  d=1200
│  │  CMD=0x01
│  LEN=8
HEAD
```

十六进制：`AA 08 01 64 00 CE FF B8 04 3A F5`（CRC 为示例值，实际需计算）

**目标：dx=0, dy=0, depth=2000mm（归中）**

```
AA 08 01 00 00 00 00 D0 07 xx xx
```

## 5. 时序要求

| 参数 | 值 | 说明 |
|------|-----|------|
| 发送频率 | 15~30 Hz | 与摄像头帧率同步 |
| 帧间隔 | 33~66 ms | |
| 帧间最小间隔 | 10 ms | 避免缓冲区溢出 |
| 超时 | 无 | 主机单向发送，不等 ACK |

### 建议 MCU 处理流程

```
串口接收中断
  → 缓存到 ring buffer
  → 主循环检查完整帧（HEAD + LEN + payload + CRC）
  → 校验 CRC
  → 解析 CMD + payload
  → 执行控制（PID → 电机）
```

## 6. 错误处理

### 6.1 主机端（发送方）

- CRC 由主机计算并附加，不检查回传
- 串口写入失败时记录日志，不重试（下一帧会覆盖）

### 6.2 机械臂端（接收方）

建议处理以下错误情况：

| 错误 | 处理 |
|------|------|
| CRC 校验失败 | 丢弃该帧，继续接收下一帧 |
| 未知 CMD | 丢弃该帧，继续接收下一帧 |
| LEN 超出范围 | 丢弃该帧，重新同步到下一个 0xAA |
| 缓冲区溢出 | 清空缓冲区，等待下一个 0xAA |

**不建议回传 ACK**（保持单向简单），如需回传请另开一个 CMD 定义。

### 7.1 回环测试

主机发送帧 → 串口回环（TX 短接 RX）→ 主机解析 → 验证一致。

### 7.2 已知测试向量

| dx | dy | depth_mm | payload（hex） | CRC（待计算） |

| 100 | -50 | 1200 | `64 00 CE FF B8 04` | 待计算 |
| -32768 | 32767 | 65535 | `00 80 FF 7F FF FF` | 待计算 |

### 7.3 Python 验证脚本

```python
from app.core.serial.protocol import encode_target, decode_frame, decode_target

# 编码
frame = encode_target(dx=100, dy=-50, depth_mm=1200)
print(frame.hex())  # 应输出 11 字节

# 解码
decoded = decode_frame(frame)
target = decode_target(decoded)
assert target.dx == 100
assert target.dy == -50
assert target.depth_mm == 1200
```
