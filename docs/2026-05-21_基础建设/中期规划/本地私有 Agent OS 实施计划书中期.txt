# 本地私有 Agent OS 实施计划书 (v3.0 最终工程版)## 一、 三层系统架构定版放弃“All in VM”或“K8s”，采用最契合当前硬件的**宿主机 + 基础设施 VM + Docker 服务层**架构。### 1. 物理与逻辑分层*   **基础设施层 (VirtualBox)**：fnosNAS、HomeAssistant（长期运行，免折腾）。*   **核心服务层 (Docker Compose)**：Agent、API、前端、DB、中间件（常驻运行）。*   **用户运行层 (Docker Containers)**：用户训练环境、Web SSH（按需弹性，cgroup 限制资源）。### 2. Docker 网络隔离规范严禁全局 `network_mode: host`，按业务划分虚拟网络：*   `frontend_net`：Nginx, Web UI。*   `backend_net`：API Gateway, OpenClaw, Perception。*   `infra_net`：PostgreSQL, Redis, NATS（不暴露外部）。*   `runtime_net`：用户训练容器（隔离运行）。### 3. 统一网关*   **引入 Nginx**：统一反向代理 `/api`, `/ws`, `/sse`, `/tts` 等路由，处理 SSL 与负载均衡。---## 二、 核心子系统设计规范### 1. 前端实时与 AI UI 系统*   **通信协议分离**：    *   **SSE**：专职 AI 文本流式输出。    *   **WebSocket**：专职系统状态与事件推送（wake, leave, metrics, runtime_status）。*   **AI 驱动 UI (禁止操作 DOM)**：    *   Agent 输出结构化 JSON（如 `{"type":"render_component", "component":"rss_card", "props":{...}}`）。    *   前端维护**组件注册表 (Registry)**，根据 JSON 动态渲染 React 组件。AI 控制状态，前端负责渲染。### 2. 消息总线 (Event Bus)*   **引入 NATS**：替代 Redis PubSub，作为全局事件中心。*   **统一事件命名**：`event.user.wake`, `event.vm.created`, `event.rss.updated` 等，解耦各微服务。### 3. 感知系统 (Presence System)*   从单一“人脸识别”升级为“存在状态感知”：    *   `presence=near` (靠近)    *   `presence=engaged` (注视屏幕/交互中)    *   `presence=away` (离开)*   结合 WebSocket 推送，实现屏幕自动唤醒/休眠与竖屏切换。### 4. Prompt 工程分层 (严禁巨型 Prompt)OpenClaw Workspace Prompt 必须动态组装：*   **Core Identity**：基础人设（固定）。*   **Runtime Context**：当前页面、用户、设备状态（动态注入）。*   **Tool Context**：当前页面可用的 Skills（动态注入）。*   **Memory Context**：仅注入向量召回的相关记忆。---## 三、 前端页面规划 (共 7 页)在原有基础上，新增两个核心管控页面：1.  **系统事件页 (中控日志流)**：实时滚动显示 NATS 事件（谁唤醒、RSS 更新、容器创建、Agent 行为），强化“工作室中枢”视觉体验。2.  **AI 记忆页 (Memory Manager)**：可视化展示 AI 记忆库，支持用户手动查看、修改、删除或禁用特定记忆。---## 四、 实施路线图 (最小闭环优先)**停止过度规划，立即进入“工作室贾维斯 Alpha”最小闭环开发。**### Phase 1：Alpha 最小闭环（当前唯一目标）只实现以下 6 个节点，跑通全链路：1.  **唤醒**：摄像头识别用户靠近 (`presence=near`)。2.  **UI 联动**：通过 WebSocket 触发前端自动切竖屏。3.  **实时语音**：Faster-Whisper 识别 + MiniMax TTS 播报。4.  **一个 Skill**：RSS 订阅读取。5.  **一个 UIAction**：Agent 输出 JSON 控制前端切换到 RSS 页面。6.  **一个 Memory**：记住并叫出用户名字。### Phase 2：技能与感知扩展*   接入日程管理、系统指标查询。*   完善 Presence System (engaged/away) 与屏幕追踪。### Phase 3：AI Studio Runtime 建设*   开发 `training-runtime-service`。*   实现 Docker 容器化训练环境创建、ttyd WebSSH、资源配额与 Agent 联动监控。### Phase 4：基础设施深度集成*   集成 fnos 状态、HomeAssistant 控制。*   上线“系统事件页”与“AI 记忆页”。
