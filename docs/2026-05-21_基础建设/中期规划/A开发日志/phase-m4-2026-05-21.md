| **AppShell** | 添加 `<SkipToContent />` + `<main id="main-content">` |

**SkipToContent 组件**
- `sr-only` 默认隐藏，`:focus` 时 fixed 显示
- 链接文本："跳到主内容"
- 跳转目标：`#main-content`

### 4. Token stream chunk 级 motion.span ✓

**TokenStream.tsx** — 新建
- 按句子边界（`。！？\n`）分割流式文本为 chunks
- 每个 chunk 独立渲染 Markdown（保持格式正确）
- 最后一个 chunk: `motion.span` — `opacity: 0→1, y: 4→0, duration: 0.18s, ease-out`
- 旧 chunks: 静态渲染（不重复动画）
- 流式光标: `animate-cursor-blink` 竖线（替代 CSS `::after` stream-cursor）
- 非流式状态：完整 Markdown 渲染（无动画）
