## Checklist 执行记录

### 1. tokens.css + dark mode + 主题切换 hook ✓

- 新建 `apps/web/src/styles/tokens.css`，定义 Claude 风格 Design Tokens
  - 颜色：暖灰底 `#F7F4EE`、墨色文字 `#1A1916`、赭石 `#B8552B`
  - 字体：Inter + Noto Sans SC（sans）、Lora + Source Serif（serif）、JetBrains Mono（mono）
  - 字号：1.2 比例尺 `--text-xs` ~ `--text-3xl`
  - 间距：4px 基准 8 级
  - 圆角：`--radius-sm/md/lg/pill`
  - 阴影：3 级柔和暖色
  - 动效：`--ease-out`、`--ease-in-out`、3 级 duration
- Dark mode 使用 `[data-theme="dark"]` 选择器
- `useTheme.ts` 重写：`class="dark"` → `documentElement.setAttribute('data-theme', resolved)`
- `Tailwind.config.ts` 同步更新：`darkMode: ["selector", '[data-theme="dark"]']`、Claude 色板、breathe/shake keyframes
- ui-kit 组件 token 名更新：`--color-surface-raised` → `--color-surface`、`--color-accent-light` → `--color-accent-soft`
- Storybook preview 适配 data-theme
