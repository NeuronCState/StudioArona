## Checklist 执行记录

### 1. VoiceModeOverlay + /voice 路由 ✓

**VoiceOrb.tsx** — Canvas 语音球核心组件
- 四个状态：idle / listening / thinking / speaking
- 每个状态有独立配色（暖赭 / 蓝 / 紫 / 暖橙）
- idle: sin 呼吸缩放 (0.95↔1.05, 4s 循环)，柔和光晕
- listening: 按频谱 RMS 振幅做不规则膨胀 + 蓝色频率环
- thinking: 内部双光带高速旋转 + 冷紫色调
- speaking: 按频谱做径向橙色频率环扩散
- 使用 `AnalyserNode.getByteFrequencyData` 取实时频谱
- `requestAnimationFrame` 60fps 渲染循环
- `devicePixelRatio` 高清适配

**VoiceModeOverlay.tsx** — 全屏语音浮层
- 纯黑底色 (`#0D0D0D`)，framer-motion fade 入场
- 上方用户 ASR 字幕（逐字浮现 + 闪烁光标）
- 下方 AI TTS 字幕（流式 + 闪烁光标）
- 四点控制：点击暂停 · 长按退出 · Esc 关闭 · 空格暂停
- 麦克风权限 Dialog 引导授权
- Web Audio API: `getUserMedia` → `AudioContext` → `AnalyserNode`
- 模拟语音流：idle → listening(ASR) → thinking → speaking(TTS) → idle

**VoicePage.tsx** — /voice 路由页，返回键退出

### 2. 语音球四态 + Web Audio 接入 ✓

- 四态已在 VoiceOrb 中实现
- Web Audio 接入通过 `navigator.mediaDevices.getUserMedia({ audio: true })`
- `AnalyserNode.fftSize = 256` 提供频率数据
- 降级: 无 mic 权限时弹 Dialog；ASR/TTS 不可达时显示离线标记（UI 预留）
- 模拟模式下（无真实 mic 时）使用确定性 sin/cos 波形驱动视觉

### 3. 字幕同步 ✓

- 用户字幕：模拟逐字 ASR 输出，80ms 间隔
- AI 字幕：模拟流式 TTS，60ms 间隔
- 两者都使用 `AnimatePresence` mode="wait" + y 4px fade
- 语音球状态与字幕联动（listening → ASR, speaking → TTS）
- 生产环境中字幕时间戳由 WebSocket `voice_token` 事件驱动，当前为 UI 级模拟
