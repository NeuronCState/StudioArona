## 发现的阻塞问题

### 问题 1：Agent Bridge SSE 流超时挂起（严重）

**现象**：Bridge 收到消息后，`session_started` 事件正常发送，但 30 秒内无任何 `token`/`tool_call` 事件，最终超时断开连接。

**根因**：Bridge spawn 的 OpenClaw 子进程使用的工作空间路径配置错误：

```
配置路径：/Users/zhangxuanning/Desktop/Studio Javis/services/agent/workspace
实际目录：/Users/zhangxuanning/Desktop/StudioJavis/services/agent/workspace
```

路径中存在空格（`Studio Javis`），但目录实际无空格，导致 SOUL.md / IDENTITY.md / TOOLS.md 等关键人设文件无法被 OpenClaw 找到，Agent 以"白纸"状态启动（回复"嘿，刚上线...你是谁？怎么称呼你？"）。

**影响范围**：
- 规划书 Phase 1 节点 2（UI 联动）依赖 Agent 正常工作
- 规划书 Phase 1 节点 5（UIAction 控制前端）依赖 Agent 正常工作
- 所有 B 的 Skill 调用链

**修复方案**：
修改 `~/.openclaw/openclaw.json` 中的 workspace 路径：

```json
"workspace": "/Users/zhangxuanning/Desktop/StudioJavis/services/agent/workspace"
```

同时确保 `services/agent/openclaw.json` 中的一致（该文件无 workspace 字段，从 `~/.openclaw/openclaw.json` 继承）。

**验证方法**：
```bash
# 修复后运行
OPENCLAW_CONFIG_PATH=./openclaw.json \
  pnpm exec openclaw agent --agent main \
  --message "你好" --thinking low --session-id verify_fix --json

# 应输出包含"阿洛娜"人设的回复，而非"刚上线"
```

### 问题 2：seed_dev_data.py PYTHONPATH 依赖问题

**现象**：
```bash
uv run python infra/scripts/seed_dev_data.py
# → 无输出，不报错，用户未创建（因为找不到 app 模块）
```

**根因**：脚本内部使用 `from app.auth.password import hash_password`，但 `pyproject.toml` 的 `pythonpath` 仅设为 `services/api-gateway`，从项目根目录运行时会话找不到模块。

**临时解法**：
```bash
DATABASE_URL=postgresql+asyncpg://javis:javis@localhost:5432/javis \
  PYTHONPATH=services/api-gateway \
  uv run python infra/scripts/seed_dev_data.py
```

**建议**：在 `infra/scripts/seed_dev_data.py` 开头加入自动 PYTHONPATH 修正逻辑，检测是否从正确目录运行。

---

### 问题 3：Perception 缺少 psutil 依赖

**现象**：
```bash
curl http://localhost:8002/api/system/metrics
# → 500 Internal Server Error
```

**根因**：perception 的 `mac.py` 依赖 `psutil`，但 uv 虚拟环境未安装。

**修复**：
```bash
cd services/perception && uv add psutil
```

之后重启 perception 服务（端口 8002）。
